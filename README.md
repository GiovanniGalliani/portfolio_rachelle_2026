# Portfolio di Rachelle Ricciardi

Portfolio personale responsive in HTML, CSS e JavaScript, senza framework o dipendenze di build. La foto (`rachelle-ricciardi.jpg`) è nella stessa cartella di `index.html` per semplificare il caricamento su GitHub.

## Anteprima locale

Apri `index.html` nel browser oppure, da questa cartella, avvia un server statico:

```bash
python3 -m http.server 8000
```

Visita `http://localhost:8000`.

## Pubblicazione

Carica nella radice del repository GitHub `index.html`, `styles.css`, `script.js` e `rachelle-ricciardi.jpg`. In Settings → Pages seleziona il branch scelto e `/(root)`. In alternativa, carica i file su Netlify senza build command.
